# NafYoung.github.io

邵扬帆 / NafYoung 个人站。深色沉浸式落地页，参考即梦官网的前端手法：

- Lenis 平滑滚动
- Hero 场景轮播 + 毛玻璃 CTA
- WebGL 圆角 / 边缘色散媒体卡（自动降级）
- IntersectionObserver 触发的进场动画

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```

推送到 `main` 后，GitHub Actions 会自动部署到 GitHub Pages。
